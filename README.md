# Успеваемость

Веб-система деканата: студенты, назначения дисциплин, оценки и отчёты.  
Next.js 16 + React 19 + SQLite (`better-sqlite3`).

## Как запустить

```bash
cd gradebook
npm install
npm run dev
```

Открыть http://localhost:3000 — сразу страница входа.

Пересоздать базу с демо-данными:

```bash
npm run db:reset
```

Если база была создана старой версией проекта (другой формат паролей), один раз выполните `npm run db:reset`.

Проверить формулу, сессии, защиту и работу с БД (71 тест):

```bash
npm test
```

Сборка к сдаче: `npm run build`, затем `npm start`. В режиме `npm start` cookie помечается `secure` и работает только на `localhost` или по HTTPS; для показа по сети без HTTPS задайте `COOKIE_INSECURE=1`.

Секрет подписи сессий берётся из переменной `SESSION_SECRET`, иначе создаётся автоматически в `data/.session-secret` (в git не попадает).

## Демо-вход

| Роль | Логин | Пароль | Куда попадает |
|---|---|---|---|
| Администратор | `admin` | `admin123` | Обзор, пользователи, журнал, выгрузка БД |
| Деканат | `dean` | `dean123` | Справочники, назначения, отчёты |
| Преподаватель | `teacher1` | `teacher123` | Журнал своих дисциплин (Соколов П.В.) |
| Студент | `student1` | `student123` | Только свои оценки (Сидорова М.И., ИС-21) |

## Что умеет система

- Вход по логину/паролю, четыре роли, чужой URL не открывается.
- Защита: пароли scrypt с солью, подписанная HMAC cookie (HttpOnly, SameSite, Secure), 5 попыток входа за 15 минут, проверка роли и «только своё» на сервере, проверка Origin, защитные заголовки, запросы с параметрами.
- Справочники (студенты, группы, дисциплины, преподаватели) и назначения: таблица, поиск, фильтры, добавление/правка в модальном окне, удаление с подтверждением.
- Журнал оценок: лаб. × 0.3 + КР × 0.3 + экзамен × 0.4. Зачёт в средний балл не входит.
- Отчёты: рейтинг группы, ведомость, сводка студента, должники, качество знаний. Excel (CSV), печать/PDF.
- Журнал действий и скачивание/восстановление файла SQLite.

## Где что лежит

| Путь | Зачем |
|---|---|
| `db/schema.sql` | Таблицы SQLite, 3НФ |
| `db/queries.sql` | Примеры SELECT с формулой GPA |
| `src/lib/db.js` | Подключение и автосид |
| `src/lib/repo.js` | Все запросы к данным |
| `src/lib/crypto.js` | scrypt паролей и HMAC-сессия |
| `src/lib/rate-limit.js` | Ограничение попыток входа |
| `src/proxy.js` | Редирект гостя на вход, проверка Origin |
| `src/app/api/` | REST API |
| `src/app/(cabinet)/` | Страницы кабинета |
| `src/components/UI/Modal.jsx` | Модалка CRUD |
| `data/gradebook.db` | Файл базы (создаётся при первом запуске) |

Средний балл **не хранится** в таблице: считается при выборке из оценок по экзаменам и диф. зачётам.
